# Cognifyz Software Development Internship

This repository contains projects and tasks completed during my Software Development Internship at Cognifyz Technologies.

## Task 1: Number Guessing Game

A simple Python-based number guessing game developed as part of the internship.

### Features

- Random number generation
- Number range from 1 to 100
- Maximum 7 attempts
- Too high / too low hints
- Invalid input handling
- Replay option
- Exception handling

### Technology Used

- Python
- Random module
- Conditional statements
- Loops
- Exception handling

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Run the following command:

```bash
python number_guessing.py
